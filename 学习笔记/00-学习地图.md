## 下一阶段：只研究一个 Tool

Agent Loop 验收完成后，从 `read` 或 `bash` 中只选一个，追踪：

```text
Tool definition
→ Tool registration
→ Tool schema 传给模型
→ 模型产生 tool call
→ 参数校验
→ Tool execution
→ Tool result
→ Agent Loop / Context
```

本阶段暂不并行研究多个 Tool，也不立即研究 edit 的安全细节。

## 记录规则

每篇模块笔记明确区分：

- **源码事实**：能由具体文件、函数或实验直接验证
- **我的理解**：对事实的解释或归纳
- **设计决定**：自己的 Agent 准备采用什么方案及原因
- **尚未验证**：当前问题、假设或需要实验确认的内容

不要把推断写成源码事实。源码位置尽量记录文件、函数和当前 commit，避免以后 Pi 更新导致笔记失真。
