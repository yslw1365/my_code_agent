# my_code_agent

通过阅读 Pi 的实现，学习 Code Agent 的核心架构，并逐步实现自己的最小 Code Agent。

## 当前阶段

正在研究 Agent Loop：

- 模型如何产生 tool call
- Agent Runtime 如何执行 Tool
- tool result 如何回到 Context
- Agent Loop 如何继续或终止

## 项目结构

- `学习笔记/`：按核心模块整理的学习笔记
- 后续将加入自己的 Agent 实现
